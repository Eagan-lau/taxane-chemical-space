# Release v1.0.0

First publication-oriented software release for construction and analysis of
the taxane reaction-grammar chemical space.

## Included

- evidence-stratified reaction-grammar preparation and T1 selection;
- strict iterative G0-G3 generation with directional event provenance;
- product acceptance, rejection, and parent-rule application audits;
- validation, sensitivity, benchmark, and chemical-space analysis workflows;
- final publication figure and molecule-catalog workflows;
- portable Conda specification, example configuration, tests, and protocol
  documentation.

## Scientific boundary

The code generates hypotheses of reaction-grammar accessibility. It does not
claim that inferred structures are observed metabolites or that individual
edges are experimentally verified enzyme reactions.
